# Vibecodium Roadmap

> Doc class: living - Owner: vibe-overseer - Last reviewed: 2026-11-26

Milestones are dependency-ordered. Each milestone's acceptance tests are written before its implementation and must pass (exit 0) before the milestone is marked done. Must-have IDs refer to `PRODUCT_SPEC.md`. The detailed per-milestone acceptance commands from the research plan (section 7) are the starting point; the milestone owner refines them into `tests/vibe/` when the milestone starts.

Status values: `done`, `in progress`, `next`, `planned`, `parked`.
